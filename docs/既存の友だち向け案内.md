# 既存のLINE友だちへの案内（LINE版・完全版）

## ねらい

1. 今いる友だちに、診断の「完全版」を楽しんでもらう（ファン化）
2. 結果を受け取るときにメッセージを送ってもらい、**プロラインに表示されていない友だちを表示させる**
3. 同時に、タイプ・テーマ・今の気分のタグを付けて、今後の配信を出し分けられるようにする

## 流れ

```
LINE公式アカウントの管理画面から、全員に「カード（リッチメッセージ）」を一斉配信
  → タップすると LINE版の診断（公開版のURL + ?from=line）が開く
  → 結果はすべて表示（「続きはLINEで」はなし）
  → 「この結果をLINEで受け取る」を押すと、合言葉が入力された状態でトーク画面が開く
  → 送信 → プロラインに表示される ＋ 詳しい鑑定文が自動で届く（タイプ別タグ付与）
```

## 準備

| 項目 | 内容 |
|---|---|
| `config.js` の `lineId` | LINE公式アカウントのベーシックID（@から始まる） |
| `config.js` の `publicUrl` | 公開版のURL（「お友だちに教える」で共有される） |
| LINE版のURL | 公開版のURLの末尾に `?from=line` を付けたもの（例：`https://○○.vercel.app/?from=line`） |
| プロラインのキーワード応答 | 合言葉6つ（みちびき／たくみ／ひらめき／つなぐ／ささえ／いやし）→ 詳しい鑑定文＋タグ。公開版と共通で使える |

## 一斉配信の作り方

プロラインにまだ表示されていない友だちにも届けるため、**LINE公式アカウントの管理画面（LINE Official Account Manager）から配信**します。

- 「リッチメッセージ」で画像を1枚作り、タップ時のリンクにLINE版のURLを設定する（カード型にしたい場合は「カードタイプメッセージ」でも可）
- 画像の例：手のイラスト＋「手相でわかる あなたの取扱説明書 ✦ LINEの皆さま限定・完全版 ✦」＋「タップして診断する（約2分）」

**一緒に送るテキスト（案）**

> いつもありがとうございます。望月ゆいです🌙
>
> LINEの皆さまへ、ささやかなプレゼントです。
> 右手を見ながら答えるだけで、あなたの才能と金運タイプがわかる
> 「手相でわかる あなたの取扱説明書」をつくりました。
>
> LINEの皆さまには、結果をすべて見られる **完全版** をご用意しています。
> 下の画像をタップして、ぜひ試してみてくださいね✋

## そのあと

- 3〜4日後に1回だけ、切り口を変えたリマインドを送る（例：「6つのタイプ、あなたはどれでしたか？」）
- 送信してくれた人はプロラインに表示されるので、以降はプロラインで出し分けて配信する
- 月末募集の案内でも「感想を送ってください」など、返信のきっかけを入れると、残りの友だちも表示されていく
